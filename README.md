# STARPlanner 🌟

一个风格简约、美观、功能丰富的「计划」网站，采用 **Zen（禅意）设计**：和纸暖白背景、鼠尾草绿与炭黑点缀、细字重无衬线标题 + 衬线正文（行高 2.0）。它的核心是一个**字卡传讯式的计划伙伴**——聊天界面里，对方把「字卡」投递给你，回复由随机抽取 + 多段拼接生成，还会主动来找你、帮你记住计划、陪你一点点完成它们。对方（伙伴）的头像、昵称都可以自定义，你也可以维护自己的**字卡库**。

- **在线体验 / 部署**：这是一个纯静态站点，可直接托管到 **GitHub Pages**。
- **数据存储**：所有数据（计划、聊天记录、伙伴形象、提醒设置）都保存在浏览器 `localStorage` 中，**不经过任何服务器**，隐私安全。

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 💌 字卡传讯 | 消息以「字卡」形式呈现（发送者 + 时间 + 正文），按日期分隔 |
| 🎴 字卡库 | **六分区**（回复 / 颜文字 / emoji / 计划提醒 / 鼓励 / 安慰）；「回复」支持**自定义分组 + 批量加入**（【】识别组名、一行一张自动切分），预置 Mochi 默认字卡，可在设置中开关 |

| ⚙️ 回复设置 | 自定义**默认字卡开关 / 回复等待时间 / 一次回复条数 / emoji 概率 / 拼接概率 / 主动频率**等 |
| 🎛️ 快捷触发 | 聊天底部快捷按钮（**安慰 / 计划提醒 / 鼓励** + **一起完成吧**）一键触发对应功能 |
| 🗓️ 周日历 | 按周查看计划与纪念日，今天高亮，可前后翻周 |
| 🕐 TA 的时刻 | 右侧可隐藏/固定面板：**日/周/月三视图**（日视图＝24 小时纵向时间轴 + 左侧时间标签 + 事件竖向色块，块高=时长×像素比、圆角、显示时间+名称）、**事件池（即时/未来/双属性）**、每 30 分钟**梯度安排**、每 2 小时**计划触发检查**、每 2 小时更新的**想法**、每 30 分钟波动的**幸福/轻松/思念度**、顶部「XX 正在 XX 中」状态、以及「一起完成」事件 |
| ⏰ 每日随机鼓励与催促 | 每天在活跃时段内**随机时刻**给你鼓励、催促，不固定时间 |
| 👤 自定义对方 | 可自定义伙伴的**昵称**、**头像**（表情或上传图片） |
| 🗒️ 计划管理 | 添加 / 编辑 / 完成 / 删除计划，支持截止时间与重要程度 |
| 🍅 陪伴番茄钟 | 专注 / 短休 / 长休循环，进度圆环、今日与累计统计、完成时伙伴发消息鼓励、结束铃声 |
| 📌 自定义纪念日 | 添加生日/纪念日等，**置顶显示**并按临近度排序，当天伙伴会送上祝福 |
| 🔔 桌面通知 | 开启后，切到别的页面也会收到浏览器通知（需页面保持打开） |
| 🌙 深浅色主题 | 一键切换浅色 / 深色模式 |
| 📱 响应式 | 桌面、平板、手机都能优雅使用 |

## 🎋 设计语言

- **风格**：苹果风 **Glassmorphism**（玻璃质感）——大背景渐变 + 柔和光斑，面板半透明 + 背景模糊 + 柔和外阴影，大容器圆角 `24px`、小控件 `12px`，避免硬边
- **点缀色**：鼠尾草绿 `#8b9a7b`、炭黑 `#3a3a3a`
- **排版**：细字重无衬线标题 + 舒适衬线正文，行高 `2.0`
- **布局**：聊天应用外壳——左侧栏（伙伴 / 纪念日 / 计划 / 功能入口）+ 右侧聊天窗 + 右侧「TA 的时刻」面板
- **可自定义**：大背景图、TA 的昵称/头像、你的昵称/头像，均在「设置」一处完成

## 🚀 部署到 GitHub Pages

### 方法一：直接上传（最简单）

1. 新建一个 GitHub 仓库（例如 `starplanner`）。
2. 把本目录下的 `index.html`、`style.css`、`app.js` 三个文件上传到仓库。
3. 进入仓库 **Settings → Pages**，在 **Source** 里选择 `main` 分支（根目录 `/`），点击 **Save**。
4. 稍等片刻，访问 `https://<你的用户名>.github.io/starplanner/` 即可。

### 方法二：命令行推送

```bash
git init
git add index.html style.css app.js README.md
git commit -m "feat: STARPlanner 计划伙伴网站"
git branch -M main
git remote add origin https://github.com/<你的用户名>/starplanner.git
git push -u origin main
```

然后在 **Settings → Pages** 选择 `main` 分支根目录并保存。

## 🛠 本地预览

直接用浏览器打开 `index.html` 即可运行，无需安装任何依赖。

> 提示：「每天不定时提醒」和「番茄钟」都依赖浏览器定时器，请保持网页标签页处于打开状态；番茄钟的结束铃声需在页面内点击过一次后才会播放（浏览器自动播放策略）。桌面通知请在首次使用时点击右上角 🔔 授权。

## ⚠️ 说明

- 由于是纯静态站点，提醒依赖浏览器定时器，**关闭页面后无法在后台推送**。这是 GitHub Pages（无后端）的天然限制。若需要真正的后台推送，可接入第三方推送服务（如 ntfy、Pushover 等）。
- 自定义头像图片会压缩后存入 `localStorage`，注意其容量上限（约 5MB）。
