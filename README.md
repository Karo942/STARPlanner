# STARPlanner 🌟

一个风格简约、美观、功能丰富的「计划」网站，采用 **Zen（禅意）设计**：和纸暖白背景、鼠尾草绿与炭黑点缀、细字重无衬线标题 + 衬线正文（行高 2.0）。它的核心是一个**字卡传讯式的计划伙伴**——聊天界面里，对方把「字卡」投递给你，回复由随机抽取 + 多段拼接生成，还会主动来找你、帮你记住计划、陪你一点点完成它们。现在支持**多个联系人**：每次开屏先选一位，各自拥有独立的聊天、TA 的时刻、纪念日、收藏与总设置。对方（伙伴）的头像、昵称可以自定义，你也可以维护自己的**字卡库**与**表情包**。

- **在线体验 / 部署**：这是一个纯静态站点，可直接托管到 **GitHub Pages**。
- **数据存储**：所有数据（计划、聊天记录、伙伴形象、提醒设置）都保存在浏览器 `localStorage` 中，**不经过任何服务器**，隐私安全。

## 👥 多联系人

- **每次开屏**都会先进入联系人选择页：极简和纸风，每位联系人是一张长方形圆角仿名片。
- 名片显示 **头像 · TA 的名字 · 「你的XX」· 上次聊天时间**；点击名片进入对应界面，右上角「⋯」可编辑或删除。
- **每位联系人独立**：聊天记录、TA 的时刻、纪念日、收藏、问问 TA 的历史、总设置（昵称 / 称呼 / 头像 / 活跃时段 / 外观等）。
- **所有联系人共享**：回复设置、周日历、计划。
- **字卡库可切换**：开屏联系人选择页右上角的极简开关，可在「共享」与「独立」之间切换。共享时所有联系人用同一套字卡库；独立时每人一套（包括表情包），互不影响。切换为共享会以当前联系人的库为准；切回独立会恢复各自之前的独立库。
- 旧版（单联系人）的 `localStorage` 数据会在首次打开时自动迁移为一位联系人，并清理旧数据。

## 💾 数据导出

在「设置 → 数据导出 / 导入」中：

- **全局**：导出全部联系人 + 共享数据（v2 结构），其中包含**问过 TA 的所有问题与答案**、每位联系人的**「你的XX」昵称**（同时提供 `nicknames` / `askTA` 汇总字段，便于查看）。
- **只有聊天 / 只有日程 / 只有各类设置**：导出当前联系人的对应范围，附带 `nickname` 与问问 TA 历史。
- **导入**同时支持新版 v2 备份与旧版单联系人备份。

## ⏰ 计划提醒 / 陪伴回复模板

在「字卡库 → 计划提醒」中：

- **计划提醒**：每条一行；`A` 会替换为计划名，`B` 会替换为截止时间（没有截止时间时为空）。原有内置提醒文案已全部移除，列表留空时使用一条内置兜底提醒。
- **接受陪伴 / 拒绝陪伴**：同样一行一条，`A` = 计划名，`B` = 陪伴时间，格式固定为 `HH:MM到HH:MM`。
- 到点提醒、快捷「计划提醒」、每日催促会使用「计划提醒」模板；「一起完成吧」的接受与拒绝分别使用对应模板。
- 例如：
  - `喵喵喵！喵喵A喵喵，喵喵！`
  - `吱吱吱吱，A吱吱！`
  - 实际回复会把 `A` 换成计划名。

## 🎋 设计语言

- **风格**：苹果风 **Glassmorphism**（玻璃质感）——大背景渐变 + 柔和光斑，面板半透明 + 背景模糊 + 柔和外阴影，大容器圆角 `24px`、小控件 `12px`，避免硬边
- **点缀色**：鼠尾草绿 `#8b9a7b`、炭黑 `#3a3a3a`
- **排版**：细字重无衬线标题 + 舒适衬线正文，行高 `2.0`
- **布局**：聊天应用外壳——左侧栏（伙伴 / 纪念日 / 计划 / 功能入口）+ 右侧聊天窗 + 右侧「TA 的时刻」面板
- **可自定义**：大背景图、TA 的昵称/头像、你的昵称/头像，均在「设置」一处完成
- **聊天气泡 CSS**：设置 →「聊天框专属 CSS」支持 `.message`（消息行）/ `.bubble`（气泡）/ `.mine`（我的气泡）/ `.sticker-message`（纯表情包）/ `.day-label`（日期标签）等类名，第三方气泡样式可直接粘贴生效；旧的 `.card` / `.card-body` 写法仍然兼容

## 🚀 部署到 GitHub Pages

### 方法一：直接上传（最简单）

1. 新建一个 GitHub 仓库（例如 `starplanner`）。
2. 把本目录下的 `index.html`、`style.css`、`app.js` 三个文件上传到仓库。
3. 进入仓库 **Settings → Pages**，在 **Source** 里选择 `main` 分支（根目录 `/`），点击 **Save**。
4. 稍等片刻，访问 `https://<你的用户名>.github.io/starplanner/` 即可。

### 方法二：命令行推送

```bash
git init
git add index.html style.css app.js README.md
git commit -m "feat: STARPlanner 计划伙伴网站"
git branch -M main
git remote add origin https://github.com/<你的用户名>/starplanner.git
git push -u origin main
```

然后在 **Settings → Pages** 选择 `main` 分支根目录并保存。

## 🛠 本地预览

直接用浏览器打开 `index.html` 即可运行，无需安装任何依赖。

> 提示：「每天不定时提醒」和「番茄钟」都依赖浏览器定时器，请保持网页标签页处于打开状态；番茄钟的结束铃声需在页面内点击过一次后才会播放（浏览器自动播放策略）。桌面通知请在首次使用时点击右上角 🔔 授权。

## ⚠️ 说明

- 由于是纯静态站点，提醒依赖浏览器定时器，**关闭页面后无法在后台推送**。这是 GitHub Pages（无后端）的天然限制。若需要真正的后台推送，可接入第三方推送服务（如 ntfy、Pushover 等）。
- 图片会先压缩再存入 `localStorage`：表情包约 160px、头像约 192px、背景约 1280px（优先 WebP，不支持时回退 JPEG/PNG）。旧版本遗留的大图会在打开时**自动压缩并去重**，表情包消息只保存图库引用，不再复制整张图片。
- 选择头像后会**立即保存**，不需要再点「保存」；如果头像保存失败（存储不足），会明确提示并回滚，不会假装成功。
- 即便如此，`localStorage` 仍有约 5MB 上限。设置页会显示当前占用；若提示已满，请到「字卡库 → 表情包」删除一些图片，或换用更小的背景图。
